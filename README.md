# Oahpa spánskkagiela

Espanjan kertaustehtävien ja läksyjen GitHub-osoite.

- [Sivuston etusivu](https://twinningfinn.github.io/oahpa-spanskkagiela/)

Opettaja käyttää edelleen entistä opettajan näkymää. Ryhmien tehtävälinkit jaetaan oppilaille erikseen.

## Toteutus

GitHub Pages näyttää alkuperäisen Oahpa spánskkagiela -sivuston koko selainikkunan täyttävässä kehyksessä. Oppilaan osoiterivillä pysyy GitHubin `github.io`-osoite. Alkuperäinen ulkoasu, tehtävät ja vuorovaikutus tulevat nykyisestä Sites-sivustosta.

Tämä on sovitusti GitHub-osoite nykyiselle palvelulle. Se ei ole Sitesistä riippumaton kopio: oppilaskoodien tarkistus, tehtäväaineisto, vastaukset ja opettajan tulokset ovat edelleen alkuperäisessä Sites-palvelussa. Sen on pysyttävä toiminnassa. Opettaja kirjautuu alkuperäisessä osoitteessa.

Tämä julkinen repositorio sisältää vain GitHub-sivun tiedostot. Se ei sisällä oppilaskoodeja, niiden tiivisteitä, salausavaimia, oppilasrekisteriä tai oppilaiden vastauksia.

## Tehtävälinkit

Nykyisen tehtävälinkin lopun voi säilyttää lisäämällä sen GitHub-osoitteeseen `#`-merkin jälkeen:

```text
Alkuperäinen: https://oahpa-spanskkagiela.washer-unfailing628.chatgpt.site/s/PAKETIN_TUNNUS
GitHub:      https://twinningfinn.github.io/oahpa-spanskkagiela/#/s/PAKETIN_TUNNUS
```

Myös `?set=PAKETIN_TUNNUS` toimii. Opettajan näkymän automaattisesti luomat linkit ja QR-koodit käyttävät edelleen alkuperäistä osoitetta; jaa oppilaille GitHub-linkki, kun haluat heidän käyttävän GitHub-osoitetta.

Selain voi käsitellä kehyksen tallennusta erillään alkuperäisen sivun tallennuksesta. Oppilaan voi siksi olla tarpeen syöttää oma koodinsa ensimmäisellä käynnillä GitHub-osoitteessa. Tulokset tallentuvat samaan palveluun.

## Julkaisu

GitHub Pages julkaisee `main`-haaran juurihakemiston. Ulkoasun tai tehtävien muutokset alkuperäisessä Sites-palvelussa näkyvät myös tässä näkymässä. GitHub-kehys ei muokkaa alkuperäistä sivustoa.
